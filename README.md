※ 本研究は生成AIの精度向上ではなく、文脈理解の構造化と圧縮に焦点を当てている。

本リポジトリは、人間同士では自然に行われている「文脈推定」を、統計的生成ではなく、文脈タイプと推論段階に基づいて構造的に可視化することを目的とした研究デモである。

従来のAIが表層的な事実や結果の処理に留まりやすいのに対し、本研究では暗黙の期待、視点差、時間参照、指示語の解釈といった文脈共有の失敗構造を段階的に推定・説明する。

これにより、低計算量・低容量でありながら「中身の濃い理解」を可能にする文脈推定モデルの可能性を示す。

本デモは、大規模言語モデル（LLM）のような統計的生成を前提とせず、文脈のズレそのものを構造化して扱う点に特徴がある。

## How to Read the Demo
1. 同一の例文を固定したままStageを切り替える
2. Stageが進むにつれて、解釈が「追加」されていく点に注目
3. 出力の増加＝情報量ではなく、文脈圧縮の深さを示す

### 文脈タイプ（A：日常的行き違い）
- 暗黙期待型：共有されていると想定された期待の不一致
- 時間参照型：時間表現の基準点のズレ
- 視点依存型：空間・順序の視点差による解釈差
- 指示語参照型：指示語の参照対象が一意に定まらないケース

## A：日常会話における文脈の行き違い
| 文脈型 | 主なズレ | 例 |
|------|--------|----|
| 暗黙期待型 | 期待・前提の不一致 | 洗剤の種類 |
| 時間参照型 | 時間基準の不一致 | 「30分後」 |
| 視点依存型 | 空間認知の差 | 左から2番目 |
| 指示語参照型 | 参照対象の競合 | 「それ」 |

※ 今回のデモではA（日常的文脈）に焦点を当てているが、
本モデルは以下のジャンルにも拡張可能である。

- B：感情・対人配慮を含む文脈
- C：社会的・制度的文脈
