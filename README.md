# subject-inference-demo
対話AIにおける段階的な主語推論と明確化をデモンストレーションするためのStreamlitデモアプリ。

## How to Read the Demo
1. 同一の例文を固定したままStageを切り替える
2. Stageが進むにつれて、解釈が「追加」されていく点に注目
3. 出力の増加＝情報量ではなく、文脈圧縮の深さを示す

## 文脈型（A：日常的行き違い）
- 暗黙期待型
- 時間参照型
- 視点依存型
- 指示語参照型

## A：日常会話における文脈の行き違い
| 文脈型 | 主なズレ | 例 |
|------|--------|----|
| 暗黙期待型 | 期待・前提の不一致 | 洗剤の種類 |
| 時間参照型 | 時間基準の不一致 | 「30分後」 |
| 視点依存型 | 空間認知の差 | 左から2番目 |
| 指示語参照型 | 参照対象の競合 | 「それ」 |

※ 今回のデモではA（日常的文脈）に焦点を当てているが、
本モデルは以下のジャンルにも拡張可能である。

- B：感情・対人配慮を含む文脈
- C：社会的・制度的文脈
